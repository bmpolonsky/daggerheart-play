# Временный патч Trystero 0.25.3

`npm ci` / `npm install` запускает `patch-trystero.mjs` через `postinstall`.
Скрипт меняет только три dist-файла закреплённых пакетов Trystero, не обращается
к сети и проверяет версию и точные участки исходника до записи. Повторный запуск
не меняет уже пропатченные файлы. При обновлении зависимости патч нужно заново
проверить или удалить после появления соответствующего исправления upstream.

Что исправлено:

- Если создание RTCPeerConnection обрывается посреди заполнения пула, уже
  созданные соединения закрываются, а исходная ошибка сохраняется.
- Незавершённые офферы учитываются до передачи владельцу. Выход из комнаты
  закрывает их; позднее завершение не возвращает ресурс в уничтоженный пул.
- Неуспешная выдача группы офферов освобождает всю группу. Уже переданные
  работающему пиру соединения не закрываются.
- Torrent announce обрабатывает отказы создания оффера и отправки, не запускает
  параллельные попытки, делает паузы 20, 40, 80, 160 и максимум 300 секунд.
  Успех сбрасывает задержку. Каждый реальный повтор виден в console.warn с
  номером попытки и задержкой; первый отказ серии передаётся в onJoinError и
  существующую диагностику маршрута. Глобальных фильтров Sentry нет.
- Оффер, завершившийся после выхода последнего подписчика, освобождается и не
  отправляется трекеру.

Исходные source map ссылки в изменённых dist-файлах удаляются, поскольку их
строки больше не соответствуют upstream-картам. Сборщик строит карту для
изменённого кода.

Проверка: `node --test tests/scripts/trystero-runtime-patch.test.mjs`.
Тесты используют установленный код зависимости с контролируемыми соединениями
и relay-примитивами: частичные отказы, отмену, живые соединения, retry/backoff и
восстановление. Они не доказывают восстановление лимита реального браузера.

Отдельно `TrysteroSyncTransport` ожидает завершения `room.leave()` перед повторным
входом и освобождает комнату при ошибке настройки. Это покрыто
`tests/unit/trystero-connection-diagnostics.test.ts`.

После выкладки уже открытым вкладкам нужна перезагрузка после сохранения мира.
Новый код не применяется к старому JavaScript автоматически и не освобождает
ресурсы других вкладок. Исправлены воспроизведённые пути утечки и цикл повторов;
первопричина всего накопления соединений в исходном браузере не установлена.
